# Portfolio Description

## Project title

**Small Office Network Infrastructure — Cisco Packet Tracer**

## Resume-ready description

Designed and implemented a Cisco Packet Tracer small-office network simulation with segmented LANs, centralized DHCP, DHCP relay, IPv4 routing, a DSL-style WAN and ISP path, default and return routing, NAT/PAT, DNS fundamentals, and structured end-to-end verification.

## Skills demonstrated

- Cisco Packet Tracer
- IPv4 addressing and subnetting
- Layer 2 switching
- Layer 3 routing
- DHCP
- DHCP relay / ip helper-address
- Static and default routes
- NAT/PAT
- ACLs for NAT matching
- DNS
- WAN concepts
- Troubleshooting
- Technical documentation

## Interview talking points

### DHCP relay

A centralized DHCP server served both subnets. The router relayed requests from the remote client network to the DHCP server.

### Routing

The office router used a default route toward the ISP, while upstream routers used return paths back toward the office networks.

### NAT/PAT

Private client traffic was translated to the office WAN address so multiple hosts could share the same outside identity.

### Troubleshooting

The build included troubleshooting a wrong external default gateway and separating IP reachability from DNS name resolution.
